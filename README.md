# 贪吃蛇 (Snake Game)

## v2.0 更新（2026）

- **难度选择**：轻松 / 标准 / 极限三档，游戏中即时生效
- **三种道具**：加速 `»`、减速 `«`、穿墙 `⇄`，每吃 4 个食物随机刷新，限时生效（加速与减速互斥）
- **暂停与方向盘**：空格键暂停，屏幕方向盘支持手机触控；最高分/长度本地持久化
- **主题皮肤**：青草 / 海洋 / 落日 / 霓虹四套配色
- **黄金食物**：5% 概率出现，吃到 +50 分并触发 9 秒彩虹蛇身

**专属彩蛋**：吃到黄金食物（或用 KONAMI 秘籍）让蛇身变彩虹。


经典贪吃蛇游戏的网页版实现，界面简洁，操作流畅。

## 功能

- **经典玩法**：控制蛇吃食物，身体不断增长
- **碰撞检测**：撞墙或撞到自己则游戏结束
- **实时分数**：顶部显示当前得分
- **游戏结束弹窗**：显示最终得分，一键重新开始
- **键盘控制**：方向键或 WASD 控制蛇的移动
- **自适应画布**：画布大小自动适配窗口
- **中英文切换**：界面支持中文/英文
- **自动全屏**：打开后自动进入全屏模式

## 游戏规则

- 使用 **↑ ↓ ← →** 或 **W A S D** 控制蛇的移动方向
- 吃到食物（深色方块）得分 +1，蛇身增长
- 撞到墙壁或自己的身体则游戏结束
- 蛇不能直接掉头（如向右时不能立刻向左）

## 使用方法

1. 用浏览器打开 `index.html`
2. 游戏自动开始，使用方向键控制蛇的移动
3. 吃到食物得分，尽量避免撞墙和撞到自己
4. 游戏结束后点击"重新开始"

## 技术栈

纯 HTML/CSS/JavaScript，Canvas 绘图。

## 彩蛋秘籍

所有小工具共用同一套彩蛋协议（EGG PROTOCOL v2.0）：

| 秘籍 | 效果 |
|------|------|
| `↑ ↑ ↓ ↓ ← → ← → B A` | 全屏彩带烟花 + 触发本应用专属彩蛋 |
| 连点页面标题 5 次 | 打开开发者模式面板 |
| 输入 `solcat` 后按回车 | 启用赛博朋克隐藏主题 |
| `Ctrl + Shift + T` | 切换赛博朋克隐藏主题 |
| 打开浏览器控制台 | 查看 SOLCAT ASCII 署名与解锁提示 |

> 提示：每个应用还藏有一个专属彩蛋，见上方 v2.0 更新说明。
