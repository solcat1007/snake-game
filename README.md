# 贪吃蛇 (Snake Game)

经典贪吃蛇游戏的网页版实现，界面简洁，操作流畅。

## 功能

- **经典玩法**：控制蛇吃食物，身体不断增长
- **碰撞检测**：撞墙或撞到自己则游戏结束
- **实时分数**：顶部显示当前得分
- **游戏结束弹窗**：显示最终得分，一键重新开始
- **键盘控制**：方向键或 WASD 控制蛇的移动
- **自适应画布**：画布大小自动适配窗口
- **中英文切换**：界面支持中文/英文
- **自动全屏**：打开后自动进入全屏模式

## 游戏规则

- 使用 **↑ ↓ ← →** 或 **W A S D** 控制蛇的移动方向
- 吃到食物（深色方块）得分 +1，蛇身增长
- 撞到墙壁或自己的身体则游戏结束
- 蛇不能直接掉头（如向右时不能立刻向左）

## 使用方法

1. 用浏览器打开 `index.html`
2. 游戏自动开始，使用方向键控制蛇的移动
3. 吃到食物得分，尽量避免撞墙和撞到自己
4. 游戏结束后点击"重新开始"

## 技术栈

纯 HTML/CSS/JavaScript，Canvas 绘图。
